# 抖音广告跳过（Douyin Ad Skipper）

一个非官方、社区驱动的 Chrome 扩展，用于跳过抖音网页版中带有明确广告标识的视频，以及用户手动标记的视频内部广告片段。

> [!IMPORTANT]
> 本项目与抖音、字节跳动、SponsorBlock 或 BilibiliSponsorBlock 没有隶属、授权或背书关系。“抖音”仅用于说明兼容的网站。

## 当前能力

- 识别“广告 / 商业推广 / 广告推广 / 推广”等明确页面标识并切换到下一条。
- 在抖音播放器控制栏内创建广告片段起止时间。
- 再次播放同一作品时自动跳过本地标记片段。
- 在选项页查看、搜索、打开和删除本地片段。
- 导入、导出本地数据。
- 完全本地运行，不上传浏览记录。

## 安装本地测试版

1. 下载或克隆本仓库。
2. Chrome 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。
6. 打开或刷新 `https://www.douyin.com/`。

## 创建片段

播放器底部清晰度按钮左侧会显示片段标记图标：

1. 广告开始时点击“片段从当前开始”。
2. 图标切换为红色取消按钮和青色结束按钮。
3. 广告结束时点击“片段现在结束”，片段立即保存在本地。
4. 点击扩展图标 →“片段管理”查看记录。

## 社区共享路线

当前 `v0.4.0` 只使用本地数据。社区共享版本的目标流程是：

```text
用户提交片段 → API 校验 → 低信任候选片段
                         ↓
                社区投票与信誉系统
                         ↓
               达到阈值后自动跳过
```

共享功能不会简单地让任意提交立即影响所有用户。计划先实现候选片段、投票、举报、限流和信誉机制，再逐步开放默认自动跳过。详见 [路线图](docs/ROADMAP.md) 和 [API 草案](docs/API.md)。

## 隐私

当前版本没有远程 API，不会上传视频浏览记录、账号信息或本地片段。完整说明见 [PRIVACY.md](PRIVACY.md)。未来引入社区服务器前，会先更新隐私说明，并提供明确的关闭选项。
