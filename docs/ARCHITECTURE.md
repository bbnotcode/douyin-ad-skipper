# 架构说明

## 当前扩展

```text
抖音页面
  ├─ content.js：活动视频、作品 ID、控制栏按钮、自动跳过
  ├─ content.css：播放器按钮和提示
  └─ chrome.storage.local
       ├─ 设置
       ├─ 累计跳过
       └─ 本地片段

popup.*   → 快速开关和入口
options.* → 片段管理、设置和备份
```

内容脚本优先通过 `data-e2e="feed-active-video"` 获取当前播放器，并兼容详情页路径、`modal_id`、`data-aweme-id` 和 `video_作品ID` 类名。

## 计划中的社区架构

```text
Chrome 扩展
  ├─ 本地缓存
  ├─ 查询客户端
  └─ 提交 / 投票客户端
           │ HTTPS
           ▼
边缘 API / Serverless
  ├─ Schema 校验
  ├─ 限流与匿名客户端身份
  ├─ 片段合并
  ├─ 投票与信誉
  └─ 审核操作日志
           │
           ▼
关系型数据库
```

远程查询失败时必须静默回退到本地片段，不能阻塞视频播放。

## 设计约束

- 扩展不依赖抖音私有接口获取视频内容。
- 共享 API 只以作品 ID 查询，不提交完整浏览历史。
- 未达到信任阈值的片段默认只显示，不自动跳过。
- 所有远程功能必须可关闭。
- 客户端不能持有管理员或数据库密钥。
